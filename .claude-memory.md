## ⚙️ Contexte technique important
- Stack : React 19 + TypeScript + Vite 8, react-router-dom 7, Supabase (auth + data), xlsx (import/export Excel)
- Lint : oxlint (`.oxlintrc.json`), script `npm run lint`
- Build : `tsc -b && vite build` ; dev : `npm run dev`
- Déploiement : Netlify — **ne jamais lancer `netlify deploy` sans demande explicite**
  (voir mémoire globale `pas-de-deploiement-auto`)
- Versioning app : incrémenter `APP_VERSION` dans `src/data/version.ts` seulement à
  chaque mise en prod Netlify réelle, pas à chaque test local (mémoire globale
  `version-app-portail-cerer`)
- Pas encore un repo git initialisé dans ce dossier (`git status` → "not a git repository")
